# Recorte observado de validação — Fendt 314

Este diretório versiona o recorte canônico em 1 Hz usado pela demonstração
local. O gzip é uma representação canônica do recorte observado de validação;
o manifesto registra a identidade dos bytes e a identidade semântica que a
importação confirma antes do replay.

Fonte: *Agricultural Load Cycles: Tractor Mission Profiles From Recorded GNSS
and CAN Bus Data*, TUM/Zenodo, DOI
[`10.5281/zenodo.14619787`](https://doi.org/10.5281/zenodo.14619787), licença
CC BY 4.0.

O recorte contém sinais GNSS/CAN observados e não contém rótulos de dano,
falha, manutenção, sinistro, culpa ou mau uso. Inferências produzidas na demo
são evidência operacional para revisão preventiva, não uma previsão desses
resultados.
